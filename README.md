# Airport Visualizer

A Java application developed as part of an Object-Oriented Programming course. The project focuses on applying OOP principles to airport data management and visualization.

## Features

- Airport data management and visualization
- Support for CSV and JSON data formats
- Object-oriented design with modular components

## Technologies

- **Language:** Java
- **Concepts:** Object-Oriented Programming, Data Structures, File I/O
- **Data Formats:** CSV, JSON

## Project Structure

- `src/` — Java source code
- `test.csv` — Sample CSV data
- `test.json` — Sample JSON data
